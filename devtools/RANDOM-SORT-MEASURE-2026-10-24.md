# Random-comparator sort (planComposition, ca2.js ~598) measured draw counts
Comparator: ((b.userAdded && P.spawnProtect)?1:0) - ((a.userAdded && P.spawnProtect)?1:0) || Math.random() - 0.5, on cells.slice().sort(...). Measured on node v22.23.3 (V8 TimSort), all elements non-userAdded so every comparison draws:
n: draws (n*log2 n) = 2:1 (2) | 5:7 (12) | 10:23 (33) | 20:62 (86) | 32:117 (160) | 33:122 (166) | 64:285 (384) | 100:494 (664) | 150:830 (1084) | 200:1196 (1529) | 300:1976 (2469)
The number and order of draws is the number and order of comparator calls of V8's TimSort (binary insertion below 32, runs + merges above), so a Rust port that "decides, JS draws" must replicate V8's exact comparison sequence, including the early-exit `||` (a draw happens only when the userAdded terms tie). Not ported. Porting the Rust-side decision is possible only by re-implementing V8's torque ArrayTimSort; not attempted, not measured against other V8 versions (the browser engine may differ from node v22.23.3).
